Test Suite

This test ensures that user data remains intact after updating the application.

Follow these steps to properly test the Passcodes application.

Step 1: Install Old Version

Download and install the older version of the Passcodes app on your device.

Step 2: Import Data

Download the provided CSV file and import it into the app to simulate existing saved passwords.

Step 3: Verify Initial Data

Open the app and ensure that all imported passwords are visible and working correctly.

Step 4: Update the App

Download and install the latest version of the Passcodes app (update over the existing installation).

Step 5: Verify Data Persistence

Open the updated app and check whether the previously saved passwords are still available.
